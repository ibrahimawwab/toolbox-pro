# Contributing to ToolBox Pro

Thanks for helping improve ToolBox Pro.

## Development
1. Use a supported Node.js LTS release.
2. Install dependencies with `npm install`.
3. Run `npm run dev`.
4. Before a pull request, run `npm run typecheck`, `npm test`, `npm run lint` and `npm run build`.

## Expectations
- Keep changes focused and document user-visible behavior.
- Add tests for utility logic and regressions.
- Prefer local browser processing for user inputs and files.
- Document privacy impacts before adding analytics, remote uploads or third-party APIs.
- Never commit secrets or real personal data.
- Do not claim a feature is complete unless it works and is tested.

## Pull requests
Explain the problem, implementation, tests performed and known limitations.
